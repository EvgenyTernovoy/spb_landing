# Мистический Петербург: лендинг

Кооперативный браузерный детектив (1–4 сыщика, 60–90 минут). Один лендинг
в образе «Дружелюбный нуар»: земля взята из игры «Загадочный СПБ» (ночь
#0f172a, синий/магия/золото, цвета классов, её же ассеты в `public/assets`),
а жизнь и формы — подходы whimsy.joshwcomeau.com: пружины-токены,
кнопки-пилюли, жёлтый пунктирный фокус, рукописные пометки Neucha, звёзды
и искры, бумажные полароиды сыщиков с лентой цвета класса; лор игры
(Минмаг, магия легальна с 1991) — в текстах.

Прежние направления дизайна (v1–v5 и хаб версий) убраны; осталась только
эта версия — она и есть приложение.

## Запуск

```bash
npm install
npm run dev
```

- `/` — лендинг целиком: шапка, герой, «Как играть», «Что внутри сценария»,
  демо-панорама, сыщики, «Для кого», FAQ, финальный CTA.

Продакшен-сборка: `npm run build && npm start`.

## Структура

```
app/
  layout.tsx      — шрифты (Sofia Sans, Neucha, Marck Script, JetBrains
                    Mono, все с кириллицей) и метаданные
  page.tsx        — только композиция секций в <main>
  globals.css     — базовый сброс; вся земля — токены в shared.module.css
components/
  shared.module.css      — токены игры/whimsy, оболочка .page, каркас
                           секций (.section/.wrap/.band/.secHead), сквигглы,
                           кнопки-пилюли, звёзды, слоты, механизм .rv
  decor.tsx              — Squiggle (подчёркивание заголовков) и Dots
  use-reveal.ts          — хук появления секций (класс in + CSS)
  top-bar/               — шапка: стекло на скролле, scroll-spy, росчерк
                           ссылок
  hero/                  — герой: параллакс, буквы-пружины, свупы, частицы
  lore/                  — строка лора и радужный разделитель
  how-play/              — «Как играть»: станции на живом следе,
                           искра-фонарик за курсором
  case/                  — «Что внутри сценария»: бенто-блоки состава
                           дела №1 — карта локаций (реальные mapPosition
                           сценария), доска улик, ростер допрашиваемых,
                           таймер, экипаж
  demo/                  — «Место происшествия»: телефон с 360°-панорамой
                           (Pano360.tsx + pano.module.css — three.js-сфера
                           и метки улик), карточки улик
  chars/                 — «Сыщики»: полароиды с наклоном за курсором
  audience/              — «Для кого»: визитки-поводы (парам, компаниям,
                           фанатам true crime, командам) — штриховые
                           иконки рисует скролл, слоганы от руки
  faq/                   — FAQ-аккордеон
  finale/                — финальный CTA и футер
  wishlist/              — модалка вишлиста «Распоряжение Минмага»:
                           нативный <dialog> (фокус-трап, Escape, top layer),
                           бумага досье со штампом «−50%» (пружина с выбросом,
                           лист вздрагивает), корешок-билет с перфорацией
                           и заявкой-почтой (поле «на бланке», подтверждение —
                           мини-штамп «принято»); вход/выход — @starting-style
                           + allow-discrete, триггеры зовут useWishlist()
```

В каждой папке секции — её `Component.tsx` и colocated `*.module.css`;
данные секций (дела, сыщики, вопросы, улики демо) лежат рядом, в начале
файла компонента. Общие для нескольких секций классы — в
`shared.module.css`.

## Точка интеграции CTA

Кнопка «Играть» в герое ведёт на якорь `#play` (финальная секция). Пока игра
собирается, финальная кнопка «В вишлист» открывает модалку со скидкой −50%
и формой почты (components/wishlist). Финальная кнопка (и «Играть дело»
в деле №1) помечены комментариями `Точка интеграции` — при подключении
бэкенда меняется их обработчик; в модалке такая же метка стоит на сабмите
формы (подписка/промокод вместо оптимистичного «Принято»).

## Технологии

- Next.js 16 (App Router), React 19, TypeScript
- CSS Modules, нативный CSS без библиотек компонентов
- `motion/react` для параллакса героя и `useReducedMotion`
- `three.js` (dynamic import, отдельный чанк) для 360°-панорамы в демо

## Доступность

- Все интерактивы — кнопки с `aria-label` / `aria-expanded`.
- При `prefers-reduced-motion` отключаются все анимации, включая параллакс
  и искру-фонарик; контент показывается сразу.
- Контраст текста выдержан; фокус виден (`:focus-visible`, жёлтое
  пунктирное кольцо whimsy).

## Движение (по мотивам whimsy.joshwcomeau.com)

- Пружины — дизайн-токены: `--spring-soft` 667мс, `--spring` 833мс,
  `--spring-bouncy` 900мс; базовые кривые cubic-bezier, при поддержке
  `linear()` заменяются на снятые с whimsy. Действуют на входы героя,
  штамп «дело №1», карточку улики, FAQ и ховеры карточек.
- Фоновая жизнь: туман дышит (64с), фонарь демо дышит (7с), точка
  «доступно» живёт, кольца улик пульсируют вразнобой (`--d`).
- Скролл-таймлайны: при `@supports (animation-timeline: …)` параллакс героя,
  обводка иконок шагов и след между станциями работают на чистом CSS
  (`scroll()`/`view()`), rAF/motion остаются запасным путём.
- Полароиды сыщиков выпрямляются и приподнимаются упругой пружиной на
  ховере; наклон за курсором лерпит JS в `--rx/--ry`.
- Всё фоновое движение закрыто `prefers-reduced-motion: no-preference`
  (opt-in), нажатия кнопок ощущаются через `scale(0.96)`.
